## 1. КРИТИЧНО: Поправка на SEO заглавието

### Текущ проблем
Заглавието на живата страница се показва като:
```
Custom DTF Transfers by Size | Ready to Press Heat Transfers – Gravity– Gravity Designs
```

**Проблеми:**
- "Gravity" е дублирано (появява се 2 пъти)
- Има двойно тире "– Gravity–"
- Заглавието е 78 символа (Google показва максимум ~60)

### Стъпки за поправка
1. Отвори **Shopify Admin** → **Products** → избери продукта
2. Скролни надолу до секцията **"Search engine listing"**
3. Кликни върху **иконката с молив** (бутон "Edit")
4. В полето **"Page title"** изтрий всичко и напиши:

```
Custom DTF Transfers by Size | Gravity Designs
```

> Това е 48 символа — перфектно за Google. Заглавието съдържа главната ключова дума "DTF Transfers" и бранда.

5. Натисни **Save** в долния десен ъгъл

### Защо е важно
Google показва заглавието в резултатите от търсенето. Дублираният текст изглежда непрофесионално и Google може да го съкрати по неудачен начин.

## 6. Добавяне на Structured Data (Schema.org)

### Текущ проблем
Страницата **НЯМА** никакъв JSON-LD structured data markup. Това означава, че Google не може да покаже:
- Звезди (рейтинг) в резултатите от търсенето
- Цена и наличност
- Rich snippets

### Стъпки за добавяне
1. В **Shopify Admin** → **Online Store** → **Themes**
2. Кликни **"..."** → **Edit code**
3. Намери файла **`sections/product-template.liquid`** (или `main-product.liquid` в зависимост от темата)
4. В **края на файла**, преди затварящия `</section>` или `{% endschema %}`, добави:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "{{ product.title | escape }}",
  "description": "{{ product.description | strip_html | truncate: 500 | escape }}",
  "image": [
    {% for image in product.images limit: 3 %}
      "https:{{ image | image_url: width: 1200 }}"{% unless forloop.last %},{% endunless %}
    {% endfor %}
  ],
  "brand": {
    "@type": "Brand",
    "name": "Gravity Designs"
  },
  "sku": "{{ product.selected_or_first_available_variant.sku }}",
  "offers": {
    "@type": "AggregateOffer",
    "priceCurrency": "USD",
    "lowPrice": "{{ product.price_min | money_without_currency }}",
    "highPrice": "{{ product.price_max | money_without_currency }}",
    "offerCount": "{{ product.variants.size }}",
    "availability": "https://schema.org/InStock",
    "url": "{{ shop.url }}{{ product.url }}"
  }
}
</script>
```

5. Натисни **Save**

## 9. Поправка на количеството по подразбиране (Qty = 0)

### Текущ проблем
Когато потребител зареди страницата, полето за количество показва **"0"** вместо **"1"**. Това означава, че клиентът трябва ръчно да увеличи количеството, преди да може да добави в количката.

### Стъпки за поправка
1. В **Shopify Admin** → **Online Store** → **Themes** → **Edit code**
2. Намери файла, който съдържа quantity input за продуктовата страница. Потърси в:
   - `sections/product-template.liquid`
   - `snippets/product-form.liquid`
   - Или потърси с Ctrl+F за `quantity` или `qty`
3. Намери input елемента, който изглежда приблизително така:

```html
<input type="text" name="quantity" value="0" ...>
```

4. Промени `value="0"` на `value="1"`:

```html
<input type="text" name="quantity" value="1" ...>
```

5. Натисни **Save**

### Алтернативен метод (ако не намериш в Liquid)
Може да е в JavaScript файл. Потърси в:
- `assets/custom.js`
- `assets/theme.js`
за реда, който задава стойността на quantity на 0.

### Защо е важно
Qty = 0 е **сериозна UX грешка**. Клиент, който кликне "Add to Cart" с количество 0, може да получи грешка и да напусне. Стандартът е винаги 1.
